# Customer Lifetime Value (CLV) Data Cleaning & Analysis 🛠️📊

This project is part of my learning journey in **Data Analytics** using Python (Jupyter Notebook).  
I worked on a **Customer Lifetime Value (CLV)** dataset and focused on **data cleaning, handling missing values, and basic analysis**.

---

## 🔍 Project Overview
- Loaded and explored the CLV dataset
- Checked dataset structure using `.info()`, `.describe()`, `.shape`, `.head()`, `.tail()`
- Identified and handled **missing values**:
  - `.isnull()` to detect nulls
  - `dropna()` to remove missing data
  - `fillna()` to replace missing values with mean/median
- Applied **encoding** techniques for categorical data
- Calculated **mean values** for selected columns


## 🚀 Skills Practiced
- Python (Pandas, NumPy)
- Data Cleaning (dropna, fillna, mean, isnull)
- Encoding categorical features
- Exploratory Data Analysis (EDA)
